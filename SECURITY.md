# Security policy

## Supported version

Only the newest published release receives security fixes.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Contact Dayaah through
the profile linked from the repository and include:

- affected version;
- Windows version;
- clear reproduction steps;
- expected impact;
- any proof-of-concept files in a safe, non-destructive form.

Ordinary crashes, device-detection failures, and Rocksmith compatibility issues
can be reported through GitHub Issues.

## Scope

The application has no updater, server, account system, telemetry, or automatic
network client. Its external links are opened only after a visible button click.
