# Code of conduct

Be respectful, constructive, and specific.

- Discuss code and behavior, not personal characteristics.
- Welcome questions from people with different experience levels.
- Do not harass, threaten, impersonate, dox, or publish private information.
- Avoid spam, deliberately misleading reports, and destructive test material.
- Maintainers may edit, hide, or remove contributions that violate these rules
  and may restrict repeat offenders.

If a situation requires private handling, contact the maintainer through the
GitHub profile linked from this repository.
